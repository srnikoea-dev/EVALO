# Nilai Siswa (Android, offline)

1. Buat repository baru di GitHub, unggah seluruh isi folder ini (termasuk folder `.github`).
2. Buka tab **Actions** > **Build APK** > **Run workflow** (juga otomatis jalan saat push ke `main`).
3. Setelah selesai, unduh **nilai-siswa-apk** dari bagian *Artifacts*, ekstrak, lalu pasang `app-debug.apk` di HP.
